# Sprint 02 — Session Infrastructure (accelerated MVP)

Status: **Implementation proposed on feature branch; not applied or verified against AWS.**

## Objective

Provision and destroy one small, explicitly tagged public-SSH EC2 bastion, before the separate enterprise baseline is complete. This sprint initially proves infrastructure only, not WireGuard.

## Entry

- Sprint 00 CI accepted on main.
- Non-root AWS SSO assumed role proven on the intended member account (user-reported / local).
- Operator must verify account ID privately, use a current public IPv4 /32, retain only the SSH PUBLIC key in Terraform and confirm cost expectations.
- ADR-0007 explicitly scopes local state as a temporary exception; no persistent bootstrap resources.

## P-tier code acceptance

- [ ] `terraform fmt -check -recursive`, offline `terraform init -backend=false`, `terraform validate`.
- [ ] `.terraform.lock.hcl` generated by actual Terraform and committed; `terraform.tfvars` and state ignored.
- [ ] CI permissions `contents: read` only; no API mutation on PR.
- [ ] Account guard, /32 SSH ingress, IMDSv2, encrypted delete-on-termination root disk, no additional paid gateway.

## H-tier live acceptance (ONLY after explicit operator approval)

- [ ] Validate role/account/region and plan diff before apply.
- [ ] Record EC2 instance ID and tags without publishing full account ID.
- [ ] Verify authenticated SSH host identity, TCP/22 access from allowed operator.
- [ ] Verify port 22 inaccessible from unauthorized public source (separate network test).
- [ ] Terraform destroy reviewed and completed.
- [ ] Independently inventory EC2/EBS/ENIs/VPC/IGW/SG/keypairs/public IP after destroy.
- [ ] Record elapsed hours and real cost evidence.

## Failure paths

- Wrong account: fail before creating resources.
- Missing SSH public key / `0.0.0.0/0`: refuse plan.
- Lost local state or interrupted destroy: stop, investigate via AWS inventory, then recover; do not silently recreate/abandon resources.
